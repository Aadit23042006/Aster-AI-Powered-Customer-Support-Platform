# Missing or Delayed Packages

## Delivery estimate

Aster & Row delivery dates are estimates, not guaranteed delivery dates. If an order is still within its current estimated delivery window, the customer should continue to monitor the shipment tracking information.

## Estimated delivery date has passed

If the current estimated delivery date has passed and the package has not arrived, the customer should contact Aster & Row support with the order ID so the shipment can be reviewed. The agent may explain the available order status and tracking information, but it must not claim that a package is lost or that a carrier investigation has been opened unless the application actually confirms that action.

## Delivered but not received

If the order status says `delivered` but the customer has not received the package, the customer should report the delivery problem to support. The agent must not claim that a carrier investigation or replacement has been opened unless a supported system action confirms it.

## Shipment delay or exception

If the order data shows a carrier delay or shipment exception, the agent should report the available status and current delivery estimate when present. An order with a shipment exception that requires investigation should be escalated to human support.
